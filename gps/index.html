Setup

Shots are always kept on this phone. Add a GitHub key to also save them to your repo and to load jobs from the Town House Designer.

How to make the GitHub key
  1. On github.com go to Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: Only select repositories, pick ASBUILT_MAKER.
  3. Permissions: Contents, Read and write.
  4. Generate, copy it and paste it above. It stays on this phone only.
Accuracy tips
  • A phone in the open is usually good to 10 to 15 ft. Next to a building it can be 30 ft or worse.
  • Turn on precise location for your browser (iPhone: Settings, Privacy, Location Services, Safari Websites, Precise Location).
  • Wait for the accuracy number to settle before saving. Re-shoot anything marked red.
